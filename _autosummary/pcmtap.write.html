pcmtap.write#

Write a stream of PCM chunks to an audio file.

.wav is written natively (32-bit float WAV, the tap’s exact samples, no dependency). Any other extension (.flac, .mp3, .m4a, .ogg…) is encoded by ffmpeg as the chunks arrive.

Functions

write_audio(path, chunks, fmt, *[, bitrate])

Write chunks to path: natively for .wav, through ffmpeg otherwise.

write_wav(path, chunks, fmt)

Write chunks to a 32-bit float WAV at path; returns the path.

write_with_ffmpeg(path, chunks, fmt, *[, ...])

Encode chunks into path with ffmpeg (format from its extension).
